# MOA (모아)

> 친구·크루가 **목표 캐릭터를 나눠 맡아** 챌린지로 함께 완성하는 모바일 웹앱.
> 완성된 캐릭터에는 '빠진 날의 흔적'까지 그대로 남아서, 목표와 조금 다른 **우리만의 캐릭터**가 됩니다.

**배포 링크**: https://gyuyeonglee90-cloud.github.io/moa/

> 데스크톱에서 열면 왼쪽에 소개, 오른쪽에 폰 프레임 안의 앱이 뜨는 포트폴리오 뷰로 보입니다. 모바일에서는 전체 화면 웹앱입니다.

## 문제 → 해결

| 문제 | 해결 |
|---|---|
| 단톡방 챌린지는 2주면 흐지부지된다. 내가 빠져도 아무도 모른다 | **부위 책임제**: 크루가 목표 캐릭터의 부위(머리 선·양쪽 눈·볼·입)를 하나씩 맡는다. 내가 빠지면 '내 부위'에만 흔적이 남아서, 벌칙은 아니지만 모두가 알아보는 책임감이 생긴다 |
| 도전이 끝나면 숫자(달성률)만 남아서 '함께했다'는 감정이 오래가지 않는다 | **흔적이 곧 개성**: 빠진 날은 그 부위가 커지거나 기울어지거나 물결 모양으로 바뀌고, 전원이 함께한 날은 반짝임으로 남는다. 완벽한 목표보다 우리 히스토리가 담긴 캐릭터가 더 애틋하다 |
| 챌린지가 끝나면 추억이 손에 잡히지 않는다 | **굿즈 상생 구조(선택)**: 완성한 캐릭터를 스티커·키링·그립톡·인형으로 만들어볼 수 있다. 가상의 사회적기업 파트너 "모아손 공방"이 제작하고, 판매가의 일부는 크루가 고른 기부처로 간다는 상생 구조를 보여준다(결제 없는 가상 주문 예약) |

## 핵심 기능

- **가이드 체험 투어**: 방문자가 가상 크루 '아침러너즈'의 일원이 되어, 초대 → 부위 맡기 → 첫 인증 → 7일 함께하기(5일차엔 직접 하루 쉬어보기) → 완성식까지 3분 안에 전체 흐름을 체험한다
- **목표 캐릭터 함께 완성하기**: 템플릿(동글/말랑/통통) × 색을 고르고, 부위 5개를 크루원이 나눠 맡는다. 부위는 인증한 날수만큼 점선에서 실선으로 그려진다
- **흔적과 좋은 흔적**: 미인증이 쌓이면 그 부위에 흔적(크기·기울기·물결)이 남고, 전원 인증한 날은 반짝임(최대 7개)으로 남는다
- **완성식**: 목표와 우리 캐릭터를 비교하고, 닮은 정도·총 인증 수·좋은 흔적 수를 확인한다
- **도감**: 완성한 캐릭터들을 모아보고, 각 캐릭터의 흔적 히스토리를 다시 본다
- **데모 컨트롤**: '다음 날로 넘기기'로 하루씩 건너뛰며 체험하고, '처음 상태로 되돌리기'로 언제든 리셋한다
- **3D 캐릭터**: 몸통과 부위 5개를 독립된 3D 오브젝트로 조립. 드래그로 회전, 탭하면 말랑하게 반응, 부위를 탭하면 담당자가 표시된다

## 기술 스택

- **React + Vite + TypeScript**
- **Tailwind CSS** — `docs/design/DESIGN_SYSTEM.md` 토큰 기반
- **Zustand + persist** — 브라우저 저장소(localStorage)에 상태 저장, 새로고침해도 유지
- **React Router (HashRouter)** — GitHub Pages에서 새로고침해도 404가 나지 않도록
- **Three.js + @react-three/fiber + @react-three/drei** — 캐릭터 3D 조립·인터랙션
- **Vitest** — 도메인 로직(흔적, 진행률, 완성 처리 등) 단위 테스트
- **GitHub Actions → GitHub Pages** — main 브랜치에 푸시하면 자동 테스트·빌드·배포

## 팀 구성

이 프로젝트는 PO·디자인·개발·3D·QA를 각각 맡은 AI(Claude) 세션이 분업해서 만들었습니다.

| 역할 | 담당 |
|---|---|
| PO | 기획·의사결정, PRD/결정 로그 관리, 세션 간 조율 |
| 디자인 | 디자인 시스템, 화면 스펙, 캐릭터 비주얼 방향 |
| 개발 | 도메인 로직, 화면 구현, 배포 |
| 3D | 캐릭터 3D 모델·인터랙션 |
| QA | 품질 검사, 버그 리포트 |
