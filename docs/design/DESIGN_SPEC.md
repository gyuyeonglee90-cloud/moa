## 1. 무드
- **다정하고 말랑하게, 유치하지 않게.** 크림색 배경, 파스텔 캐릭터, 포인트 컬러는 **그레이프(#6A5AE0) 하나만** 쓴다.
  ↳ 파스텔 6색이 캐릭터 몫이라 포인트는 그 사이에서 묻히지 않는 보라 계열로 정했다. 흰 글자와의 대비가 5.3:1이라 버튼에 쓸 수 있다.
- 글씨는 크게, 여백은 넉넉하게, 한 화면에 한 목적(토스식). 장식은 캐릭터와 이펙트에만 넣고 UI는 담백하게 둔다.
  ↳ 유치함은 대부분 UI 장식에서 생긴다. 귀여움은 캐릭터에만 몰아준다.
- 외곽선은 순검정 대신 **잉크 #3D3450**(보라빛 남색)을 쓴다.

## 3. 캐릭터 시스템 (`docs/design/character/`)

### 3-1. 파일
| 종류 | 파일 | 색 |
|---|---|---|
| 알 | `egg.svg` | 껍질은 크림색 고정, 무늬는 `currentColor` (몸 색이 비쳐 보임 ↳ PRD 5-2) |
| 몸통 | `body-{round\|soft\|spiky}-stage{1\|2\|3}.svg` | `fill="currentColor"`. 바닥 그림자 포함 |
| 표정(입) | `face-{happy\|normal\|sad}.svg` | 고정 |
| 파츠 | `part-{hat\|eyes\|cheek\|prop}-{1..4}.svg` | 고정 |
| 이펙트 | `fx-sparkle.svg` (완성 반짝이), `fx-combo.svg` (콤보) | 고정, 애니메이션용 class 포함 |
| 미리보기 | `preview.html` | 모든 조합 확인용, 파일로 바로 열 수 있다 |

파츠 이름: 모자 1 비니 / 2 고깔 / 3 새싹 / 4 리본 · 눈 1 동글눈 / 2 반짝눈 / 3 웃는눈 / 4 안경 · 볼터치 1 발그레 / 2 빗금 / 3 하트 / 4 주근깨 · 소품 1 꽃 / 2 풍선 / 3 깃발 / 4 별봉
몸통 이름: round 동글 / soft 말랑 / spiky 뾰족

### 3-2. 조립 규칙 (개발 필독)
모든 파일은 `viewBox="0 0 200 200"`이다. 하나의 `<svg>` 안에 각 파일의 내부 요소를 아래 순서로 겹친다(아래에 적힌 것이 위에 그려진다).
```
fx-combo (콤보 중일 때)
body-{type}-stage{n}           ← 이미 단계 크기로 그려져 있다. 변형 없이 그대로 쓴다
<g transform=STAGE_T>          ← 파츠는 단계 배율로 묶는다
  part-cheek → face → part-eyes → part-hat → part-prop
</g>
fx-sparkle (stage3일 때)
```
- `STAGE_T = translate(100 178) scale(k) translate(-100 -178)`이고 **k = stage1 0.62 / stage2 0.82 / stage3 1.0**이다. 기준점은 발바닥 중앙 (100,178)이다.
  ↳ 파츠를 한 벌만 그리고 3단계 × 3몸통에 재사용하려면, 몸통 쪽을 같은 배율로 그리는 방식이 가장 단순하다.
- 단계별로 보이는 파츠 (↳ PRD "파츠 일부만 보임")

| 단계 | 몸통 | 보이는 것 |
|---|---|---|
| 0 알 | `egg.svg`만 | 파츠 없음 |
| 1 아기 | stage1 (작고 정수리에 털 한 가닥) | 눈, 볼, 표정 (모자·소품 숨김) |
| 2 성장 | stage2 (발이 생김) | 전부 |
| 3 완성 | stage3 (팔·배 하이라이트) | 전부 + `fx-sparkle` |

- 색 적용: 바깥 `<svg style="color: #FFB89E">`처럼 지정한다.
- 구현 팁: 파일 내용을 `?raw`로 import해 바깥 `<svg>`를 걷어 내고 `dangerouslySetInnerHTML`로 넣거나, `.tsx` 컴포넌트로 옮긴다. `<img>`로 쓰면 currentColor가 적용되지 않으니 쓰지 않는다.

### 3-3. 기준점 (stage3 좌표, k=1)
| 기준점 | 좌표 | 비고 |
|---|---|---|
| 발바닥 중앙 / 배율 원점 | (100, 178) | |
| 정수리(모자 밑단) | (100, 62) | 몸통 꼭대기: 동글 y56, 말랑 y62, 뾰족 y60(가시 끝 32). 모자 밑단은 y58~73로, 세 몸통 모두를 덮는다 |
| 눈 | (78,106), (122,106) | 안경은 반지름 15 |
| 볼 | (63,124), (137,124) | |
| 입 | (100,126) | 표정은 y120~139만 쓴다 → 눈·볼과 겹치지 않는다 |
| 손(소품 잡는 점) | (160,140) | 소품은 x150~192, y40~152 범위 |
| 몸통 폭 | 동글 x38~162 / 말랑 x30~170 / 뾰족 x40~160 | |

### 3-4. 표정 매핑
`face-happy` 😆 오늘 크루 인증률 100% · `face-normal` 🙂 50% 이상 · `face-sad` 🥺 50% 미만. 슬픈 표정도 입 모양만 살짝 바뀐다(눈물·땀 없음 ↳ 처벌 없음).

### 3-5. 사용 크기
홈 카드 96px · 상세 히어로 220px · 인증 시트 미니 64px · 도감 그리드 120px · 졸업 카드 240px · 크루 파츠 썸네일 40px

### S2 챌린지 만들기 (3스텝)
상단에 ← 뒤로 + 진행 점 3개(●○○)를 두고, 하단 고정 '다음' 버튼을 둔다.

- Step2: 미리보기는 stage3 기준으로 보여 준다(완성될 모습). 친구 파츠는 미리 붙어 있고, '나'는 친구가 쓰지 않은 카테고리에서 1개를 고른다. 친구 파츠 칸은 잠금 아이콘과 함께 "민지가 붙임" 캡션.
- Step3: 이름 기본값은 랜덤 추천이고 🎲로 다시 뽑는다. 추천 풀은 개발이 정한다(예: 몽글이, 콩떡이, 보리, 뭉치).

- 단계 다음 기준까지 남은 인증 수를 보여 준다. ↳ 숫자보다 '다음 변화'가 동기를 준다.

### S4 인증하기 (바텀시트, 높이 약 70%)

```
┌──────────────────────────┐

│ [ 스탬프 5종 64px 그리드 ] │ 🌟💪📚🌱🎉
│  또는 [사진 추가 영역 4:3] │
│ 한 줄 메모 (선택)          │
│ [ 오늘은 어땠나요?   0/40 ]│
```

- 사진은 선택 사항이고, 스탬프가 기본 선택이라 바로 완료할 수 있다. ↳ 3분 체험에서 입력 장벽을 없앤다.
- 완료하면 시트가 닫히고 S3에서 성장 모션(7장)이 재생된다.

### S5 졸업식

```
│ 🎊 (컨페티)               │

└──────────────────────────┘
```

- 엔딩 문구: 85% 이상 "완전체로 졸업했어요!", 85% 미만 "자기만의 모습으로 졸업했어요" (↳ 실패가 아니라 다른 엔딩).
- 도감에서 들어오면 컨페티 없이 같은 카드를 보여 준다(S7과 공유).

### S6 도감
```
┌──────────────────────────┐
│ 도감                      │ title
│ 함께 졸업시킨 친구 4마리    │ body text-2
│ ┌─────────┐ ┌─────────┐  │ 2열 그리드, gap 12

│ │ 14일·92% │ │ 7일·64% │  │ caption

│   🏠 홈         📖 도감    │
└──────────────────────────┘
```
- 최신순으로 정렬한다. 완성 엔딩 카드는 우상단에 ✨ 배지를 단다.
- 빈 상태: 실루엣 알 3개 + "아직 졸업한 친구가 없어요. 첫 졸업을 향해!"

### S7 도감 상세
- 위쪽은 졸업 카드(8장), 아래쪽은 **여정 앨범** 타임라인이다.
```
│ ── 여정 앨범 ──           │
│ Day 1 · 11/01   😀😀😐😀😀 │ 그날 인증 아바타
│  [스탬프][사진][스탬프] →   │ 가로 스크롤 썸네일 72px
│  "첫날 화이팅!" — 민지     │
│ Day 2 · …                 │
```
- 좌측에 2px `line` 세로선과 날짜 점 8px을 둔다. 전원 인증한 날은 점을 `point`로 칠하고 🔥를 붙인다.

### 데모 컨트롤 (플로팅)
```
                 ┌───────────────┐
                 │ ⏩ 다음 날로   │  pill 높이 44, text-1 배경 + 흰 글씨
                 └───────────────┘
                     ↺ 초기화       caption 링크, 누르면 확인 다이얼로그
```
- 위치: 폰 화면 우하단, 탭바 위 16px / CTA가 있는 화면에서는 CTA 위 16px. `shadow float`.
- 좌상단에 `DEMO` 배지(caption, `warning-soft`)를 둔다. ↳ 실제 기능이 아님을 방문자에게 분명히 알린다.
- '다음 날로' 후 토스트: "하루가 지났어요 · 친구 3명이 인증했어요"
- 초기화 확인: "데모를 처음 상태로 되돌릴까요?" [취소] [초기화]
- 데스크톱에서는 소개 패널의 체험 가이드에도 같은 버튼을 둔다(8장의 폰 프레임 밖, 중복 제공).

## 6. 데스크톱 포트폴리오 레이아웃 (≥ 1024px)
```
┌───────────────────────────────────────────────────────────┐
│  bg #FFF8F2 + 우측에 point-soft 큰 원 장식(blur)             │
│                                                           │
│  ┌ 소개 패널 (max 440) ┐        ┌──── 폰 프레임 ────┐        │
│  │ [로고 캐릭터 48] MOA │        │ ┌──────────────┐ │        │
│  │ 같이 키우면,         │        │ │              │ │        │
│  │ 끝까지 가요 (40/800) │        │ │   앱 390×844 │ │        │
│  │ 한 줄 소개 (18 text-2)│        │ │              │ │        │
│  │                     │        │ │              │ │        │
│  │ ◆ 함께 만드는 캐릭터  │        │ └──────────────┘ │        │
│  │ ◆ 벌칙 없는 성장      │        │                  │        │
│  │ ◆ 졸업 카드 & 도감    │        └──────────────────┘        │
│  │                     │                                    │
│  │ 3분 체험 가이드        │                                    │
│  │ 1 '독서' 카드 열기    │                                    │
│  │ 2 오늘 인증하기       │                                    │
```

- 두 열은 가운데 정렬, 간격 80px. 폰 프레임은 390×844 + 베젤 12px(`#2B2438`), radius 56, shadow phone이다. 화면 높이가 900 미만이면 프레임을 `scale(min(1, (100vh-48)/868))`로 줄인다.
- 한 줄 소개: "친구들과 함께 캐릭터를 만들고 키우는 챌린지 앱. 끝나면 우리의 여정이 졸업 카드로 남아요."
- 핵심 기능 3개: 각각 아이콘 32 + heading + caption 1줄.
  - 함께 만드는 캐릭터: "크루가 파츠를 하나씩 붙여 만든 우리만의 캐릭터"
  - 벌칙 없는 성장: "빠져도 혼나지 않아요. 같이 하면 더 크게 자랄 뿐"
  - 졸업 카드 & 도감: "숫자 대신 캐릭터와 앨범으로 남는 기록"
- 체험 가이드 단계는 현재 진행 단계를 `point`로 하이라이트한다(선택, 상태를 읽을 수 있을 때만).
- 1024px 미만이면 소개 패널을 숨기고 앱을 전체 화면으로 띄운다(모바일 그대로).

## 8. 졸업 카드 (4:5 고정, 기준 360×450)
```
┌────────────────────────────┐  radius 24, 배경: 캐릭터 색 → #FFFFFF 세로 그라데이션
│ MOA 졸업장          No.004 │  caption, point
│                            │
│        [캐릭터 200]         │  fx-sparkle 포함(완성 엔딩일 때)
│                            │
│         몽글이              │  title 24/800
│   하루 한 챕터 독서          │  label text-2
│   2026.10.25 – 11.07       │  caption text-3
│ ┌──────┬──────┬──────┐     │  surface 80% 박스, radius md
│ │ 92%  │ 64회 │ 🔥 9일│     │  number 22 / caption
│ │달성률 │총 인증│최고콤보│     │
│ └──────┴──────┴──────┘     │
│ 🏅 개근상  🐰 민지 (14회)     │  label
│ 🧩 민지가 준 비니 · 준호가 준  │  caption, 최대 2줄
│    반짝눈 · 서연이 준 꽃 …    │
└────────────────────────────┘
```
- 패딩 24이고, 위에서부터 헤더 20 / 캐릭터 영역 200 / 이름 블록 / 통계 / 기여 순서로 쌓는다.
- `aspect-ratio: 4/5`로 고정한다. 화면에서는 너비 100%(최대 360)로 쓰고, 이미지 저장 시에는 1080×1350으로 렌더링한다.
- 카드 안에 버튼 등 인터랙티브 요소를 넣지 않는다(이미지로 저장되기 때문).
- 조사: "민지가 / 준호가 / 서연이" — 받침이 있으면 '이가', 없으면 '가'. 간단히 처리하려면 "민지 → 비니" 형식으로 대체해도 된다.

## 9. 제안 (PRD 범위 밖, PO 판단용)
1. 졸업 카드 배경을 엔딩별로 다르게(완성: 홀로그램 그라데이션)하면 수집욕이 커진다.
2. 데스크톱 체험 가이드 단계를 앱 상태와 연동해 자동으로 체크하면 3분 체험 성공률이 올라간다.
3. 파츠를 카테고리당 5종으로 늘릴 여지가 있다(현재 4종, PRD 허용 범위 4~5종).
