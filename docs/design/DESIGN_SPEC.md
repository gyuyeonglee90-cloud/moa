## 1. 캐릭터 에셋 (`docs/design/character/`)

| 파일 | 내용 |
|---|---|
| `template-round.svg` | 동글 템플릿 |
| `template-soft.svg` | 말랑 템플릿 |
| `template-chubby.svg` | 통통 템플릿 |

> ⚠️ **캐릭터 생김새는 보류 중이다**(대표가 재검토, PO 지시). 이 문서는 구조만 확정한다: 템플릿 + 부위 5개 + 흔적 변형 + id 규칙. 1-3장의 좌표 값과 현재 SVG는 새 방향이 정해지면 바뀔 수 있다.
| `fx-sparkle.svg` | 좋은 흔적 반짝이 7개 (`#spark-1`~`#spark-7`) |
| `preview.html` | 템플릿 3종 × 6색 × 4상태(목표 / 진행 50% / 완성 / 흔적), 흔적 단계, 반짝이 7개를 보여 준다. 안의 `renderCharacter()`는 **개발 참고용 구현 예시**다 |


### 1-1. 파일 구조 (세 템플릿 공통)
```
<svg viewBox="0 0 200 200">
  <defs> moa-{t}-grad (방사형 그라데이션, var(--char-light/base/deep))
         moa-{t}-soft (블러 1.6) · moa-{t}-fillclip > rect#moa-{t}-fillrect </defs>
  #shadow
  #body  data-cx data-cy data-top data-bottom   (.goal 점선 외곽 / .fill 그라데이션, clip 적용)
  #hair  #eyeL  #eyeR  #cheek  #mouth            ← 기본 버전
  #hair-wavy … #mouth-wavy  (style="display:none") ← 물결 버전
</svg>
```
부위 그룹 안의 클래스는 세 가지다.
- `.goal`: 점선 실루엣(`#8A857F`, 굵기 3, dash 6 8)
- `.ink`: 검정 실선(`pathLength="100"`)
- `.fill`: 흰자·눈동자·볼처럼 면으로 칠한 부분

### 1-2. 상태를 그리는 규칙
| 상태 | 처리 |
|---|---|
| 색 | 바깥 `<svg>`의 style에 `--char-light/base/deep`을 지정한다(DESIGN_SYSTEM 1-3의 6색) |
| 몸통 차오름 | 크루 인증률 r일 때 `#moa-{t}-fillrect`의 y를 `bottom − (bottom − top) × r`로, height를 `200 − y`로 바꾼다. r = 1이면 `#body .goal`을 숨긴다 |
| 부위 진행 p (인증 일수 ÷ 기간) | `.ink`는 `stroke-dasharray="{p×100} 100"`, `.fill`은 원래 opacity × p. p = 1이면 `.goal`을 숨긴다 |
| 흔적 (미인증 n회) | 부위 그룹에 `translate(cx cy) rotate(R) scale(S) translate(−cx −cy)`를 적용한다. cx, cy는 `data-cx`, `data-cy` 값이다 |
| 물결 | n ≥ 3이면 기본 그룹을 숨기고 `-wavy` 그룹을 보이게 한 뒤, 같은 transform을 적용한다 |
| 좋은 흔적 | 전원 인증한 날 수 k(최대 7)만큼 `fx-sparkle`의 `#spark-1..k`를 겹친다 |

**흔적 수치 (PRD 5-3 그대로)**: S = n=0이면 1, 그 외에는 `min(2, 1.25 + 0.1 × max(0, n−3))`. R = n ≥ 2이면 15°. 물결 = n ≥ 3.

### 1-3. 기준점 (data-cx, data-cy)
| 부위 | round | soft | chubby |
|---|---|---|---|
| body (top~bottom) | 100,110 (38~182) | 100,110 (38~182) | 100,118 (54~182) |
| hair | 100,44 | 108,30 | 100,50 |
| eyeL / eyeR | 76,100 / 124,100 | 78,104 / 122,104 | 70,108 / 130,108 |
| cheek | 100,128 | 100,132 | 100,136 |
| mouth | 100,140 | 100,144 | 100,146 |

**반짝이 7개 좌표** (켜지는 순서대로): ① 178,44 ② 22,66 ③ 186,122 ④ 14,150 ⑤ 150,14 ⑥ 46,18 ⑦ 180,180
↳ 첫 3개를 얼굴에서 먼 좌우 바깥에 번갈아 두어, 1~3개만 있어도 균형이 맞게 했다. 흔적으로 2배까지 커지는 부위와도 겹치지 않는다.

### 1-4. 개발 필수 사항
1. **인라인 SVG만 사용한다.** `<img>`로 넣으면 CSS 변수와 부위 조작이 동작하지 않는다.
2. **인스턴스마다 id 접미사를 붙인다**(`moa-round-grad` → `moa-round-grad-3`). 그리고 `url(#…)` 참조도 함께 바꾼다. 하지 않으면 한 화면의 캐릭터들이 같은 그라데이션과 clip을 공유해서 몸통 차오름이 깨진다.
3. 캐릭터를 크게 키우면 부위가 viewBox 밖으로 나갈 수 있다(입 2배, 반짝이). `overflow: visible`을 쓴다.
4. 접근성: `<svg role="img" aria-label="라임색 동글 캐릭터 뽀짝이, 완성도 72%, 입과 왼쪽 눈에 흔적">` 형식으로 붙인다. 반짝이는 장식이 아니라 정보이므로 라벨에 "좋은 흔적 3개"를 넣는다.
5. 사용 크기: 홈 카드 112 · 상세 히어로 220 · 완성식 비교 각 150 · 도감 타일 120 · 굿즈 목업 140 · 히스토리 썸네일 56

### S1 홈
- 히어로: "좋은 아침, 나 👋"(h1)와 오늘 할 일 요약 말풍선("오늘 인증 1개 남았어요"). 우측에 원형 44 아이콘 버튼 `+`(aria-label "새 챌린지 만들기")를 둔다.
- 시트 안에는 진행 중인 챌린지 카드를 **전체 폭 타일**로 세로 나열한다.
```

│ [캐릭터112]  아침러너즈 │ eyebrow
│              뽀짝이 만들기│ h3
```

- 내가 아직 인증하지 않았으면 카드 하단에 "오늘 인증하기 →" 텍스트 버튼(높이 44)을 둔다.
- 빈 상태: 점선 템플릿 + "아직 함께 그리는 캐릭터가 없어요" + 주요 버튼 "챌린지 만들기".
- 접근성: 카드 전체가 하나의 링크(`aria-label="뽀짝이 만들기, 5일째, 72%, 오늘 인증 전"`). 상태는 아이콘과 글자로 함께 표시한다.

### S2 챌린지 만들기 (3단계)
상단에 ← 와 "1/3 정보" 같은 글자 단계 표시를 두고, 하단에 고정 주요 버튼을 둔다.
| 단계 | 구성 | 버튼 문구 |
|---|---|---|
| 1 정보 | 이름 입력(라벨, 16px, 도움말 "예: 아침 30분 걷기"), 기간 세그먼트 7/14/21일, 크루 이름 입력 | "목표 캐릭터 고르러 가기" |
| 2 목표 캐릭터 | 히어로에 선택한 템플릿을 **완성형**으로 크게 + 점선 미리보기 토글. 템플릿 3종은 타일 3개(라벨 동글/말랑/통통), 색 6개는 원형 44 스와치(이름 라벨 포함, 선택 시 ✓), 캐릭터 이름 입력 + 🎲 추천 | "부위 나누러 가기" |
| 3 부위 나누기 | 캐릭터 위에 부위 라벨 칩(머리 선/왼쪽 눈/오른쪽 눈/볼/입)을 띄운다. 아래 리스트에서 크루원별로 부위를 고른다. 남는 부위는 자동으로 '공동'이 되고 "전원 인증한 날만 그려져요"라는 안내를 단다 | "챌린지 시작하기" |
- 오류 예방: 이름이 비어 있으면 버튼을 비활성하지 않고, 누르면 "챌린지 이름을 적어 주세요"와 함께 입력칸으로 포커스를 옮긴다(원인 + 해결 방법).
- 스와치는 색 이름이 `aria-label`이고, 선택 상태는 ✓ 아이콘과 `aria-pressed`로 함께 알린다.

- 콕 찌르기: ⏳ 아바타를 탭하면 토스트 "👉 서준에게 콕! 찔렀어요"(`role="status"`).

### S4 인증하기 (바텀시트)
- 상단: "오늘의 인증"(title)과 내 부위 미리보기 56("왼쪽 눈을 그려요").
- 세그먼트: 스탬프(기본) / 사진. 스탬프는 5종 64px 버튼(🌅🏃📚🌱🎉, 각각 라벨 있음). 사진은 4:3 업로드 영역이고, 지원 형식(JPG·PNG·HEIC)을 미리 적어 둔다.
- 메모 입력: 라벨 "한 줄 메모(선택)", 카운터 0/40.
- 주요 버튼 "인증하고 내 부위 그리기".
- 완료하면 시트가 닫히고 히어로에서 그리기 모션(5장)이 나온 뒤, 토스트 "왼쪽 눈이 그려졌어요 · 되돌리기"(5초)가 뜬다.
- 오류: 용량 초과 → 자동으로 줄이고 "사진을 가볍게 줄여서 올렸어요". 형식 오류 → "이 형식은 열 수 없어요. JPG나 PNG로 골라 주세요".
- 접근성: 포커스를 시트 안에 가두고, Esc로 닫으며, 닫히면 포커스를 원래 CTA로 되돌린다.

- 닮은 정도는 숫자만 보여 주고 평가하는 문구는 쓰지 않는다. 85% 이상이면 "목표에 아주 가까워요", 그 외에는 "우리 이야기가 가득 담겼어요".
- 흔적 카드 목록은 가로 스크롤에 이전/다음 버튼(44)을 같이 둬서 키보드로도 넘길 수 있게 한다.
- 접근성: 비교 그림은 하나의 `role="img"`로 묶고 라벨은 "목표 뽀짝이와 우리 뽀짝이 비교. 우리 뽀짝이는 입이 15° 기울고 왼쪽 눈이 25% 커졌어요".

### S6 도감
- 히어로: "도감"(h1)과 말풍선 "함께 완성한 친구 4마리".
- 2열 벤토. 타일 배경은 캐릭터 tint, 내용은 캐릭터 120 + 이름(h3) + "7일 · 닮은 정도 82%"(caption). 굿즈를 예약한 캐릭터는 "🎁 굿즈 예약" 배지를 단다.
- 빈 상태: 점선 템플릿 3개 + "아직 완성한 친구가 없어요. 첫 완성을 향해!"

### S7 도감 상세 (완성 카드)
- 완성 카드는 4:5(360×450)다. 헤더 "moa 완성 카드 No.004" · 목표(작게, 점선) + 우리(크게) · 이름과 기간 · 3칸 통계(닮은 정도 / 총 인증 / ✨) · 부위 담당 5줄 · 흔적 요약 1줄.
- 카드 아래에는 흔적 타임라인(S3 '흔적'과 같은 컴포넌트)과 앨범이 온다.
- 굿즈를 예약했으면 "🎁 아크릴 키링 가상 예약 · 기부처: 환경" 타일을, 아니면 보조 버튼 "굿즈로 만들기"를 둔다.

### S8 굿즈 만들기 (4단계, 상단에 "1/4 종류" 표시)
| 단계 | 구성 |
|---|---|
| 1 종류 | 2×2 벤토: 스티커 팩(흰 테두리 다이컷 원형) · 아크릴 키링(반투명 테두리 + 고리) · 그립톡(원형, tint 배경 + 흰 6px 링) · 미니 인형(채도 75% + 아래 그림자). 각 타일은 목업 140 + 이름 + 가상 가격(예: 키링 9,000원) + 선택 ✓ |
| 2 미리보기 | 선택한 굿즈를 크게 보여 준다(우리 캐릭터 그대로, 흔적 포함). 문구 "흔적까지 그대로 담겨요". 수량 스테퍼(− 1 +, 각 44)를 둔다. 기본값은 크루 인원 4개 |
| 3 상생 구조 | **인포그래픽**: 가로 100% 막대를 4칸(55/15/15/15)으로 나누고 칸마다 글자 라벨을 넣는다. 아래 범례 4줄에는 색칩 + 항목 + 금액(가격 × 비율)을 적는다. 막대 색은 lime/pink/sky/sun base 장식색이고 글자는 ink다. 그 아래 흐름 4단계(🛒 주문 → 🧵 가상 파트너 '모아손 공방'이 제작 → 💝 15% 기부 → 📦 배송)를 둔다. **기부처 선택**: 아동 / 동물 / 환경 칩(라디오 그룹)이고, 챌린지 주제에 맞춰 하나에 "추천" 배지를 단다(걷기 → 환경) |
| 4 가상 주문 예약 | 요약 카드(굿즈, 수량, 기부처, 기부 예정액) + 안내 박스(notice 아이콘 + 글자) **"포트폴리오 데모라서 실제 주문과 결제는 되지 않아요"** + 주요 버튼 "가상 주문 예약하기". 완료 화면은 캐릭터 + "예약했어요! 도감에 굿즈 배지가 붙었어요" + "도감에서 보기" |
- 파트너 이름은 가상의 '모아손 공방'으로 정한다. ↳ 실제 기관명을 쓰지 않으면서(D19), 앱 이름과 연결되어 가상임이 자연스럽게 드러난다.
- 접근성: 비율 막대는 `role="img"`로 처리하고 라벨 "판매가 구성: 제작 55%, 기부 15%, 배송 15%, 운영 15%"를 붙인다. 범례는 실제 텍스트로 쓴다(색만으로 구분하지 않는다).

### 가이드 코치 (투어, PRD 8-1)
- 형태: 화면 하단, 주요 버튼 바로 위에 붙는 **흰 코치 카드**(레벨 2 그림자, 반경 24)다. 왼쪽 위에 "가이드 3/6"(eyebrow)을 두고, 본문(body)과 [다음 행동 버튼]을 넣는다. 오른쪽 위에는 "가이드 건너뛰기" 텍스트 버튼을 둔다.

- 코치 카드는 `role="dialog" aria-modal="false"`이고, 단계가 바뀔 때 `aria-live`로 읽힌다.

### 데모 컨트롤 (플로팅)
- 폰 화면 오른쪽, 탭바 위 16px에 검정 알약 "⏩ 다음 날로"(높이 44)를 둔다. 옆에 원형 44 "⋯" 버튼을 두고, 누르면 메뉴(가이드 다시 보기 / 처음 상태로 되돌리기)가 열린다.
- 왼쪽 위에는 상시 배지 "DEMO"를 둔다(흰 배경, eyebrow).
- 넘긴 뒤 토스트: "5일째가 됐어요 · 친구 3명이 인증했어요".
- 초기화는 확인 시트로 묻는다: "처음 상태로 되돌릴까요? 진행 중인 챌린지, 인증, 도감 기록이 모두 처음으로 돌아가요." [취소] [처음 상태로 되돌리기].
- 데스크톱에서는 같은 버튼을 소개 패널에도 둔다.

### 데스크톱 (≥ 1024px)
왼쪽 소개 패널(최대 440)과 오른쪽 폰 프레임(390×844, 베젤 12 `#000`, 반경 56, 레벨 2 그림자)을 가운데 정렬하고 간격은 80이다.
- 소개 패널: wordmark "moa" · "목표 캐릭터를 크루가 나눠 맡고, 챌린지로 함께 완성하는 앱" · 핵심 기능 3개(부위 책임제 / 흔적이 곧 개성 / 굿즈 상생) · 3분 체험 가이드 6단계(현재 단계는 accent 점 + 굵게) · [GitHub] [데모 초기화].
- 1024px 미만이면 패널을 숨긴다.

## 4. 모션 (DESIGN_SYSTEM 8장 구체화)
| 연출 | 내용 | 시간 / 이징 |
|---|---|---|
| 내 부위 그리기 | `.ink`의 stroke-dasharray가 이전 p에서 새 p로 늘어나고, `.fill`이 opacity로 나타남 | 700ms `cubic-bezier(.2,.8,.2,1)` |
| 몸통 차오름 | fillrect의 y 이동 | 600ms, 그리기 시작 후 200ms 지연 |
| 통통 튀기 | scale 1 → 1.06 → 0.98 → 1 | 450ms `cubic-bezier(.34,1.56,.64,1)` |
| 흔적 생김 | 부위 rotate ±6° 흔들림 2회(240ms) → 새 scale·rotate로 이동(400ms) + 토스트 | 640ms |
| 반짝이 추가 | 새 spark가 scale 0 → 1.2 → 1 + 회전 45° | 500ms 스프링 |
| 대기 | translateY 0 ↔ −2px, scale 1 ↔ 1.02 | 3s 무한 ease-in-out |
| 완성식 | 우리 캐릭터가 목표 점선 위에 겹쳐 나타남(400ms) → 둘이 좌우로 갈라짐(500ms) → 흔적 카드가 80ms 간격으로 올라옴 | 약 1.6s |
| 코치 강조 링 | box-shadow 맥박 0 → 6px | 1.4s 무한 |
- `prefers-reduced-motion`이면 반복 동작, 흔들림, 맥박을 끄고 opacity 전환(200ms)만 남긴다. 단, 그리기는 결과 상태로 즉시 바뀐다.

## 5. 흔적 문구 가이드
**원칙**: 주어는 친구 이름, 동사는 '쉬어갔다', 결과는 캐릭터의 변화로 쓴다. 쓰지 않는 말: 실패, 벌칙, 놓쳤다, 망쳤다, 깨졌다.
1. "4일차 · 서준이 쉬어간 날, 입이 살짝 커졌어요"
2. "5일차 · 오늘 쉬어간 덕분에 왼쪽 눈이 25% 커졌어요"
3. "6일차 · 서준이 한 번 더 쉬어서 입이 살짝 기울었어요"
4. "민지가 세 번 쉬어간 볼은 몽글몽글 물결이 되었어요"
5. "지우의 머리 선은 조금 더 자유분방해졌어요"
6. "3일차 · 모두 함께 인증한 날, 반짝이가 하나 생겼어요 ✨"
7. "오른쪽 눈은 다 같이 그리는 부위라, 모두 모인 날만 한 칸씩 그려져요"
8. "흔적이 생긴 자리는 우리 이야기가 남은 자리예요"

## 6. 제안 (PRD 범위 밖, PO 판단용)
1. 완성 카드에 "흔적 지도"(부위별 흔적 수를 점으로 표시)를 추가하면 공유하고 싶은 마음이 커진다.
2. 굿즈 미리보기에서 흔적을 켜고 끄는 토글을 둘지 검토하면 좋다. 단, '흔적이 곧 개성'이라는 컨셉과 충돌할 수 있다.
