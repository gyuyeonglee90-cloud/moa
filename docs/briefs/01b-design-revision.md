## 할 일
1. **캐릭터 SVG 재작업** (`docs/design/character/`) — 기존 파일은 전부 정리한다
   - `template-{round|soft|chubby}.svg`: 하나의 파일에 `<g id="body">`, `<g id="hair">`, `<g id="eyeL">`, `<g id="eyeR">`, `<g id="cheek">`, `<g id="mouth">`를 넣는다. 부위마다 `data-cx`, `data-cy`(변형 기준점)를 적고, 물결 버전 `<g id="{part}-wavy">`도 함께 넣는다
   - 몸통은 그라데이션 구체, `var(--char-light/base/deep)`을 쓴다. 얼굴 선은 순검정 굵은 선
   - `fx-sparkle.svg` 1개와 반짝이 7개 좌표를 문서로 정리
   - `preview.html`: 템플릿 × 6색 × (목표 점선 / 진행 50% / 완성 / 흔적 예시)
2. **`DESIGN_SPEC.md` v3**: 화면 S0~S8 + 가이드 코치 + 데모 컨트롤. 레퍼런스 구조(캐릭터 히어로 + 말풍선 → 겹치는 시트 → 벤토 타일 → 떠 있는 알약 탭)로 그리고, 각 화면에 접근성 메모를 단다
   - S3에는 부위별 담당자 표시(부위를 탭하면 담당자와 인증 일수), 흔적 히스토리 타임라인
   - S5에는 목표 vs 우리 비교, 닮은 정도, 흔적 카드
   - S8 굿즈: 4종 목업, 상생 가격 구조 인포그래픽(55/15/15/15), 기부처 선택, "가상 주문 예약" + 데모 안내 문구
3. 흔적 문구 가이드: 다정한 톤의 예시 10개를 쓴다("서준이 쉬어간 날, 입이 살짝 커졌어요"). "실패", "벌칙"이라는 말은 쓰지 않는다
