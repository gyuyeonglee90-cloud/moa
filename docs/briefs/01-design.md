## 제한 시간: 35분
개발 세션이 **동시에** 프로젝트 골격을 만들고 있다. 너는 `docs/design/` 폴더만 수정한다. `src/` 등 다른 폴더는 건드리지 않는다.

## 산출물
### 1. `docs/design/DESIGN_SPEC.md`
- **무드**: 다정하고 말랑한 톤, 파스텔 + 선명한 포인트 컬러 1개. 유치하지 않게(토스/Finch 사이)
- **디자인 토큰**: 색(배경, 표면, 텍스트 3단계, 포인트, 성공/경고, 캐릭터 6색), 타이포(Pretendard, 사이즈 스케일), 간격, 모서리 반경, 그림자. Tailwind 설정에 바로 옮길 수 있게 hex/px 값으로 작성
- **화면별 스펙** S0~S7 + 데모 컨트롤: 모바일 390px 기준 와이어(ASCII 박스 그림이면 충분), 구성 요소, 상태(빈 상태, 인증 완료, 미인증), 주요 문구(카피)
- **데스크톱 포트폴리오 레이아웃**: 왼쪽 소개 패널(앱 이름, 한 줄 소개, 핵심 기능 3개, 체험 가이드) + 오른쪽 폰 프레임
- **모션**: 인증 → 성장 게이지 증가 → 단계 변화(진화) → 졸업식 연출. 각각 지속 시간과 이징 값 명시
- **졸업 카드** 레이아웃(이미지로 저장될 카드이므로 비율 4:5 고정)

### 2. `docs/design/character/` — 캐릭터 SVG 에셋
- 모든 파일은 `viewBox="0 0 200 200"` 하나로 통일한다(레이어를 겹쳐서 조립하기 때문)
- 몸통 3종 × 단계별 형태: `body-{round|soft|spiky}-stage{1|2|3}.svg`, 알 1종 `egg.svg`
- 몸통 색은 `fill="currentColor"`로 그려서 코드에서 6색 중 하나를 입힐 수 있게 한다
- 파츠: 모자 / 눈 / 볼터치 / 소품 4개 카테고리 × 각 4종 → `part-{category}-{1..4}.svg`
- 표정 3종(😆🙂🥺 대응): `face-{happy|normal|sad}.svg` (눈 파츠와 겹치지 않게 입 중심으로)
- 파츠 좌표는 몸통 3종 모두에 자연스럽게 얹히도록 기준점을 문서에 적는다
- `docs/design/character/preview.html`: 모든 조합을 한 화면에서 확인할 수 있는 미리보기 페이지
