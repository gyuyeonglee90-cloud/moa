# MOA (모아) — PRD v2.0

> 친구·크루가 **목표 캐릭터를 나눠 맡아** 챌린지로 함께 완성한다. 빠진 날의 흔적까지 담긴 **우리만의 캐릭터**는 원하면 굿즈로 만들어 상생 구조로 판매한다.
> 작성: PO (Claude) · 2026-11-07 · 상태: **확정 (v1의 '성장형 캐릭터'는 폐기 — D16)**

---

## 1. 한 줄 정의
목표 캐릭터를 크루가 부위별로 나눠 맡고, 매일 인증으로 그려 나간다. 인증을 빠뜨린 날은 그 부위에 **흔적**(커짐, 기울어짐, 물결선)으로 남아서, 완성된 캐릭터는 목표와 조금 다른 **우리만의 캐릭터**가 된다.

## 2. 문제 & 사용자
| 구분 | 내용 |
|---|---|
| 타깃 | 혼자서는 작심삼일이라 친구·크루와 함께 도전을 이어가고 싶은 20~30대 |
| 문제 1 | 단톡방 챌린지는 2주면 흐지부지된다. 내가 빠져도 아무도 모른다 |
| 문제 2 | 도전이 끝나면 숫자만 남아서 '함께했다'는 감정이 오래가지 않는다 |
| 해결 1 | **부위 책임제**: 내가 빠지면 '내 부위'에 흔적이 남는다 → 처벌은 아니지만 모두가 알아보는 책임감 |
| 해결 2 | **흔적이 곧 개성**: 완벽한 목표 모습보다, 우리 히스토리가 담긴 캐릭터가 더 애틋하다 |
| 해결 3 | **굿즈화(선택)**: 손에 쥘 수 있는 기념품으로 남기고, 제작·판매는 사회적기업과 상생 |

## 4. 범위
### 포함 (MVP)
1. 온보딩 + **가이드 체험 투어** (8-1)
2. 홈: 진행 중인 챌린지 카드(목표 대비 완성도 + 오늘 인증 현황)
3. 챌린지 만들기: 정보 → **목표 캐릭터 고르기**(템플릿 3종 × 6색) → **부위 나눠 맡기**
4. 챌린지 상세: 목표 실루엣 위에 그려지는 우리 캐릭터, 부위별 담당자, 오늘 현황, **흔적 히스토리**
5. 인증하기: 사진(선택) 또는 스탬프 + 한 줄 메모 → 내 부위가 그려지는 연출
6. **완성식**: 목표 vs 우리 캐릭터 비교 + 흔적 히스토리 카드
7. **굿즈 만들기(선택)**: 종류 선택 → 미리보기 → 상생 가격 구조 → 가상 주문 예약
8. 도감: 완성된 캐릭터 모음
9. 데모 컨트롤: 다음 날로 ⏩ / 가이드 다시 보기 / 데모 초기화

### 제외
로그인·보안, 서버, 실시간 동기화, 푸시, 채팅, 실제 친구 초대, **실제 결제·배송**, 다국어

## 5. 핵심 메커닉
### 5-1. 목표 캐릭터 & 부위 나누기
- 템플릿 3종(동글 / 말랑 / 통통) × 6색 중 하나를 크루가 고른다 = **목표 모습**
- 캐릭터는 **아기 동물**(곰 / 토끼 / 여우 계열의 오리지널 디자인)이고 **부위 5개**로 나뉜다: 왼쪽 귀 · 오른쪽 귀 · 눈 · 코·입 · 꼬리 (몸통은 공동 소유) — D26
- 크루원이 부위를 하나씩 맡는다(4명이면 부위 하나는 '공동'으로 남는다 → 전원 인증한 날만 그려짐)

### 5-2. 그려 나가기
- 처음에는 목표 모습이 **점선 실루엣**으로 보인다
- 담당자가 인증할 때마다 그 부위가 점선에서 실선으로 조금씩 그려진다(기간 N일 중 인증 일수만큼)
- 몸통 색은 크루 전체 인증률만큼 차오른다(아래에서 위로)

### 5-3. 흔적 (빠진 날의 기록 — 처벌 아님)
담당자가 하루 인증하지 않으면 그 부위에 흔적이 쌓인다. 누적 횟수로 결정한다(로직 단순화).

| 그 부위의 누적 미인증 | 흔적 |
|---|---|
| 1회 | 크기 +25% |
| 2회 | + 15° 기울어짐 |
| 3회 이상 | + 선이 물결로 바뀜, 3회째부터 매회 크기 +10% (3회 1.35, 4회 1.45 … 최대 2배) |

- **닮은 정도** = 100 − 부위별 감점의 평균. 부위 감점 = (scale − 1) × 100 + (기울어짐이면 10) + (물결이면 15), 최소 0%

- **좋은 흔적**도 있다: 전원 인증한 날마다 캐릭터 주변에 반짝이 1개(최대 7개)
- 흔적마다 히스토리를 남긴다: "4일차 · 서준이 쉬어간 날 → 입이 25% 커졌어요"
- 문구는 늘 다정하게. "실패", "벌칙"이라는 말은 쓰지 않는다

### 5-4. 완성식
- 마지막 날 다음 자동으로 열린다
- **목표 vs 우리** 나란히 비교, **닮은 정도**(흔적이 없을수록 높음, 표시만 하고 평가하지 않음)
- 흔적 히스토리 타임라인, 부위별 담당자와 인증 일수, 인증 앨범

### 5-5. 굿즈 (선택)
- 완성식과 도감 상세에서 "굿즈로 만들기"를 누르면 진입한다(필수 아님)
- 종류 4가지: 스티커 팩 · 아크릴 키링 · 그립톡 · 미니 인형 → 우리 캐릭터를 입힌 목업 미리보기
- **상생 구조(예시, 가상)**: 제작은 취약계층을 고용하는 가상의 사회적기업 파트너가 맡는다. 판매가는 아래처럼 나뉜다

| 항목 | 비율 |
|---|---|
| 제작 (사회적기업 일자리) | 55% |
| 크루가 고른 기부처 | 15% |
| 배송·포장 | 15% |
| MOA 운영 | 15% |

- 크루가 기부처 카테고리를 고른다(예: 아동 / 동물 / 환경 — 챌린지 주제와 연결해서 추천)
- 주문은 **"가상 주문 예약"**으로 끝난다. 결제 화면은 없고, 화면에 "포트폴리오 데모라서 실제 주문은 되지 않아요"라고 명시한다
- 파트너 이름은 **가상의 이름**만 쓴다. 실제 기관명은 쓰지 않는다

## 7. 더미 데이터
- 나 + 친구 4명
- 진행 중 챌린지 2개(자유 모드용): A "아침 30분 걷기" 7일 중 4일째, B "하루 한 챕터" 14일 중 13일째
- 완성된 챌린지 3개(흔적이 서로 다른 캐릭터, 그중 1개는 굿즈 예약 완료 상태)
- 자유 모드에서 '다음 날로'를 누르면 친구 인증은 확률(70~90%)로 정해진다

## 8-1. 가이드 체험 투어 (핵심 시연 흐름, 약 3분)
방문자는 가상 크루 **'아침러너즈'**(나, 지우, 민지, 서준)의 일원이 된다. 친구들의 행동은 스크립트로 고정해서 항상 같은 이야기로 흘러간다.

| 단계 | 방문자 행동 | 일어나는 일 |
|---|---|---|
| 1. 초대 | 지우의 초대장 → "크루 합류하기" | 목표 캐릭터 '뽀짝이'(라임 · 동글) 공개 |
| 2. 부위 맡기 | 남은 부위 중 **왼쪽 귀** 고르기 | 지우 = 꼬리, 민지 = 눈, 서준 = 코·입, 오른쪽 귀 = 공동 |
| 3. 첫 인증 | 스탬프 + 메모 | 내 왼쪽 귀가 반투명에서 또렷하게 채워짐 |
| 4. 함께 7일 | '다음 날로'를 누른다. **5일차에는 가이드가 "하루 쉬어볼까요?"라고 제안** | 3일차 전원 인증 → 반짝이 / 4일차 서준이 쉼 → 입이 커짐 / 5일차 내가 쉼 → **내 왼쪽 귀만 커져서 짝짝이 귀가 됨** / 콕 찌르기 |
| 5. 완성식 | 목표 vs 우리 비교, 흔적 히스토리 | "우리만의 뽀짝이" 완성 |
| 6. 굿즈 (선택) | 아크릴 키링 선택 → 상생 구조 확인 → 가상 주문 예약 | 도감에 등록되고 투어 완료 → 자유롭게 둘러보기 |

- 언제든 "가이드 건너뛰기"를 누를 수 있고, 다시 볼 수 있다

## 9. 성공 기준
- 방문자가 3분 안에 부위 맡기 → 인증 → 흔적 → 완성 → 굿즈까지 체험한다
- 모바일/데스크톱에서 깨지지 않고 WCAG 2.2 AA를 충족한다
