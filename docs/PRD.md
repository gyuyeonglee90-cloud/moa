# MOA (모아) — PRD v1.0

> 친구·크루와 **함께 캐릭터를 만들고 키우는** 챌린지 앱. 도전이 끝나면 캐릭터가 '졸업'해서 도감에 남는다.
> 작성: PO (Claude) · 2026-11-07 · 상태: **확정**

---

## 1. 한 줄 정의
크루가 함께 한 마리의 캐릭터를 만들고, 매일 인증으로 키우며, 챌린지가 끝나면 그 여정이 담긴 **졸업 카드**를 남기는 앱.

## 2. 문제 & 사용자
| 구분 | 내용 |
|---|---|
| 타깃 | 혼자서는 작심삼일이라 친구·크루와 함께 도전을 이어가고 싶은 20~30대 |
| 문제 1 | 단톡방 챌린지는 2주면 흐지부지된다. 내가 빠져도 아무도 모르고, 결과도 남지 않는다 |
| 문제 2 | 도전이 끝나면 숫자(달성률)만 남아서 '해냈다'는 감정이 오래가지 않는다 |
| 해결 | ① **공동 소유 캐릭터**: 내가 빠지면 '우리' 캐릭터가 덜 자란다 → 느슨한 책임감 ② **졸업 + 도감**: 끝나면 크루의 기록이 담긴 캐릭터 카드로 남는다 |

## 3. 레퍼런스에서 가져온 것 / 버린 것
| 레퍼런스 | 가져온 것 | 버린 것 |
|---|---|---|
| Finch (펫 키우기 자기관리) | 귀엽고 다정한 캐릭터 성장, **벌칙 없는 긍정 피드백** | 1인 중심 구조 |
| Duolingo Friends Quest | 친구와 **공동 목표 게이지**, 함께 채우는 쾌감 | 경쟁, XP 랭킹 |
| Habitica Party | 파티원의 행동이 모두에게 영향 | 내가 빠지면 친구가 데미지를 입는 처벌 구조(압박감 큼) |
| 토스 / 당근 UI | 큰 글씨, 넉넉한 여백, 한 화면 한 목적 | — |

**차별점**: 기존 앱은 결과를 '숫자'로 남기지만, MOA는 친구들이 같이 만든 **캐릭터와 앨범**으로 남긴다.

## 4. 범위
### 포함 (MVP)
1. 온보딩(포트폴리오 방문자용 소개 + "체험 시작")
2. 홈: 진행 중인 챌린지 카드(캐릭터 + 진행률 + 오늘 인증 현황)
3. 챌린지 만들기 + **캐릭터 함께 만들기**
4. 챌린지 상세: 캐릭터, 성장 게이지, 오늘의 크루 인증 현황, 인증 피드
5. 인증하기: 사진(선택) 또는 스탬프 + 한 줄 메모 → 성장 애니메이션
6. **졸업식**: 챌린지 종료 시 최종 캐릭터와 결과 카드
7. **도감**: 졸업한 캐릭터 모음과 각 여정 앨범
8. **데모 컨트롤**: '다음 날로 ⏩' / '데모 초기화' (방문자가 3분 안에 졸업까지 체험)

### 제외 (하지 않음)
로그인·회원가입·보안, 서버/실시간 동기화, 푸시 알림, 채팅, 실제 친구 초대, 결제, 다국어

## 5. 핵심 메커닉
### 5-1. 캐릭터 함께 만들기
- 챌린지를 만든 사람이 **몸통 모양**(3종: 동글 / 말랑 / 뾰족)과 **색**(6종)을 고른다
- 크루원은 각자 **파츠 1개**를 붙인다(모자 / 눈 / 볼터치 / 소품 등, 카테고리별 4~5종)
  - 데모에서는 친구들 파츠가 미리 붙어 있고, '나'만 직접 고른다
- 캐릭터 이름은 크루가 짓는다(직접 입력, 기본값은 랜덤 추천)
- 각 파츠에는 누가 붙였는지 기록된다 → 졸업 카드에 "○○가 준 모자"로 표시

### 5-2. 성장
- 진행률 = 크루 전체 누적 인증 수 / (인원 × 기간일수)
- 단계(이 기준으로 확정):

| 단계 | 진행률 | 시각 변화 |
|---|---|---|
| 0. 알 | 0~19% | 파츠 색이 비치는 알 |
| 1. 아기 | 20~49% | 작은 몸통, 파츠 일부만 보임 |
| 2. 성장 | 50~84% | 몸통이 커지고 모든 파츠가 보임 |
| 3. 완성 | 85% 이상 | 최종형 + 반짝이 효과 |

- 졸업할 때 최종 단계는 최종 진행률로 결정된다(85% 미만이면 '성장' 단계로 졸업, 실패 아닌 '다른 엔딩')

### 5-3. 기분 & 크루 콤보
- 기분: 오늘 크루 인증률 100% 😆 / 50% 이상 🙂 / 50% 미만 🥺 (처벌 없음, 표정만 바뀜)
- **크루 콤보**: 전원 인증한 날이 연속된 일수. 콤보가 이어지는 동안 캐릭터 주변에 이펙트
- 미인증 친구 아바타를 탭하면 **'콕 찌르기'** 토스트(더미)

### 5-4. 졸업 & 도감 ("끝나고 남는 것")
- 마지막 날이 지나면 졸업식 화면이 자동으로 열린다
- 졸업 카드 내용: 캐릭터 최종형, 이름, 기간, 달성률, 총 인증 수, 최고 크루 콤보, **개근상**(최다 인증 멤버), 멤버별 파츠 기여
- 여정 앨범: 일자별 인증 사진/스탬프와 메모 타임라인
- 졸업 카드 **이미지 저장**(PNG) — 시간이 남을 때만 하는 추가 기능(Nice-to-have)

## 7. 더미 데이터
- 나 + 친구 4명(닉네임, 이모지 아바타)
- 진행 중 챌린지 2개
  - A "매일 아침 30분 걷기" 7일 중 4일째 (평범하게 진행 중인 상태)
  - B "하루 한 챕터 독서" 14일 중 13일째 (다음 날로 넘기면 바로 졸업 → 데모 핵심 흐름)
- 졸업 완료 챌린지 3개(도감이 비어 보이지 않게, 엔딩 단계는 서로 다르게)
- '다음 날로'를 누르면 친구들 인증은 확률(70~90%)로 자동 생성
